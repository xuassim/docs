Pabbly est une plateforme d'automatisation qui vous permet de vous connecter à différents logiciels tiers, similaire à Zapier et Integromat.

### Comment se connecter à Pabbly

Pour commencer à vous connecter à votre compte Pabbly, suivez ces étapes :

1. Allez dans les **Intégrations** dans le menu de gauche.
2. Choisissez **Pabbly**.

### Comment ajouter LineChat à votre compte Pabbly

Une fois le bouton ci-dessus pressé, il vous dirigera vers une page web. À partir de là, appuyez sur le bouton **Demmarrer l'integration de Pabbly**.

Connectez-vous et acceptez le partage de l'application avec votre compte : 

<img height="200" src="https://res.cloudinary.com/dfp1qo2jy/image/upload/v1725803489/Screenshot_2024-09-08_155109_iedsoc.png" />

Lorsque vous êtes connecté à Pabbly, il vous dirigera vers le tableau de bord principal de Pabbly (ouvre une nouvelle fenêtre).

### Configurer votre automation

À partir de là, vous pouvez aller dans **Pabbly Connect** et créer votre automation. Lorsque vous recherchez des applications, tapez **Chatbot App** (l'application utilisee par LineChat sur Pabbly) et il devrait apparaître maintenant.

Sélectionnez l'action et/ou le déclencheur, puis appuyez sur **Connecter** pour sélectionner la connexion au chatbot.

Vous devez alors ajouter votre cle API pour finaliser la connexion.

<Info>
Si vous ne savez pas comment trouver ou créer votre jeton API LineChat, appuyez [ici](/shopify).
</Info>

Une fois inséré, appuyez sur **Enregistrer** et votre compte devrait être connecté et votre Workflow configure.
